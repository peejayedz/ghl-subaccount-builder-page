# ghl-subaccount-builder-page (Moved)

The LFMP Builder no longer runs here. It lives on the team site **https://lfmp-admin.pages.dev** (Cloudflare Pages, behind Google sign-in), deployed from the private `ghl-subaccount-builder` repo by `.github/workflows/admin-site.yml`.

This repo now publishes only the **Moved** page (`index.html`, a copy of `admin-site/moved.html` in the Builder repo) with the shared `lfmp-ui.css`, `lfmp-login.css` and `fonts/`. Old links (`dashboard.lawfirmmarketingpros.com/ghl-subaccount-builder-page/`, `peejayedz.github.io/ghl-subaccount-builder-page/`) show it, with a button to the new site.

The GHL OAuth callback is not here: it is `peejayedz/lfmp-oauth`.
