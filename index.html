Connect GitHub.

This browser has no GitHub token saved yet. It is stored only here, encrypted with the builder password.

Create the token (one time per person)

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Token name: Sub-account Builder. Expiration: 90 days (or your choice).
  3. Resource owner: the account that owns the builder repo.
  4. Repository access: Only select repositories → ghl-subaccount-builder and leadpro-kpi (one token for the Builder and the KPI admin).
  5. Permissions → Repository: Actions, Contents and Secrets: Read and write. Variables: Read-only. Metadata: Read (added automatically).
  6. Generate, copy the token and paste it below. If the owner is an organization that needs approval, an owner approves it under Org settings → Personal access tokens → Pending requests.
